# Accidental_Drug_Related_Deaths

## Description ##
This repository contains code for analyzing the dataset for "Accidental_Drug_Related_Deaths". The project uses multiple classification models to build and assess a machine learning model for set objectives. The objective is to determine the presence of the attribute "Any Opioid" using demographic and location factors. This will provide insights to determine which classification algorithm is most suitable to predict the presence of "Any Opioid". 

Throughout the project will show the data preprocessing step to clean and prepare data for analysis. A classification model with evaluation metrics determines how each model performs when predicting the presence of "Any Opioid". Cross-validation is used to evaluate the performance of each model. Lastly, data visualisation allows proper visualisation to interpret the results.
